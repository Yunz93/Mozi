# 快速上手

欢迎使用 **墨知**。它把本地文件夹当作知识库，笔记就是普通的 `.md` 文件，不绑定云端账号，也不改成专有格式。

## 30 秒走一遍主路径

1. **写作**：左侧文件树浏览知识库；用 **新建笔记**（默认 `Cmd/Ctrl+N`）开一篇新稿。工具栏可在 **编辑 / 分屏 / 预览** 之间切换（默认 `Cmd/Ctrl+3`）。内容会自动保存，也可以手动保存（默认 `Cmd/Ctrl+S`）。
2. **问库**：打开工具栏的 **问库**，问一句：`上次关于发布流程的结论是什么？` 点「生成回答」一次即可；点引用会跳回原文。需要先看来源时用「仅检索」。
3. **发出去**：打开 [[03-发布与问库]]，用工具栏导出 **长图 / PDF**，或发布到 **博客 / 微信公众号草稿**。

粘贴图片会落到知识库里的附件目录，预览里直接可见。

## 小提示

- 没有 API Key 时，写作、预览、导出仍然完整可用；问库需要配置 AI 或本地模型。
- 空行输入 `/` 可选行列插入表格，或直接写 `/3x4`。也可用 **命令面板**（默认 `Cmd/Ctrl+Shift+P`）搜索「插入表格」，快捷键 `Cmd/Ctrl+Shift+T` 会插入 3×3。
- 用 **命令面板** 搜索「发布」「问库」。
- 侧边栏搜索、当前文件查找、目录大纲等，可在 **设置 → 快捷键** 里查看或改绑。
- 示例笔记可以随便改；你改过的文件不会被后续同步覆盖。不需要的话，整份「示例笔记」文件夹删掉也行。
