# 从第一篇笔记开始

欢迎使用 **墨知 2.0.2**。选一个本地文件夹当作知识库，就可以开始写。笔记保存为普通 `.md` 文件，图片和附件也留在文件夹里。

这四篇示例可以边读边改。先写一小段，再试着插入表格、链接和图片，最后把它导出或分享出去。

## 先写，再整理

1. 点击左侧品牌旁的 **新建笔记** 加号，或按 `Cmd/Ctrl+N`，给笔记起个名字。
2. 点击顶部靠前的编辑图标，悬停提示为「实时预览」。光标所在处可以编辑，其他位置显示排版效果。
3. 空行输入 `/`，选择表格、待办、代码块或提示块。输入 `/3x4` 可以快速插入表格。
4. 点击编辑图标右侧的 **阅读** 图标检查成稿。内容会自动保存，也可以按 `Cmd/Ctrl+S` 手动保存。

![实时预览中的写作练习|900](resources/01-live-writing.png)

_实拍演示知识库：标题、待办、提示块和表格都在同一篇笔记里。_

下面这份小清单可以直接勾选：

- [ ] 新建一篇自己的笔记
- [ ] 写一个标题和两段正文
- [ ] 粘贴一张图片
- [ ] 切换到阅读模式检查排版

> [!tip] 不知道某个按钮做什么？
> 把鼠标停在工具栏图标上可查看提示。按 `Cmd/Ctrl+Shift+P` 打开命令面板，搜索「插入表格」「小知助手」或「导入微信读书笔记」。

默认字体跟随 macOS 或 Windows 的系统无衬线字体。**设置 → 界面** 可以切换浅色、金属灰深色与主题色，自定义取色器就在预设颜色后面。左下角点击知识库名称可切换知识库，旁边的齿轮打开设置。

![金属灰工作区与顶部图标顺序|900](resources/23-theme-dark.png)

阅读模式上方的属性表与正文同宽；不想显示时，在 **设置 → 编辑器** 关闭「阅读模式显示属性」。这不会删除笔记里的属性数据。

AI 增强入口在顶部「小知助手」右侧。开始后可查看准备、分析和整理结果的提示，处理完成后先预览，再决定是否应用到原文。

## 让笔记互相连接

在正文中输入 `[[笔记名]]`，就能建立 Wiki 双链。试着打开 [[02-Obsidian-内联语法示例|双链与附件]]，再用其中的链接返回这里。

粘贴图片会保存到知识库的附件目录。移动整份知识库时，把附件一起带走，图片链接才能继续使用。

需要查找内容时，可以用左侧搜索；需要看当前文章的结构时，打开右下角 **大纲 / 链接**。

## 常用快捷键

`Cmd` 对应 macOS，`Ctrl` 对应 Windows。以下为默认键位，可在 **设置 → 快捷键** 查看和修改。

| 动作               | 快捷键                 |
| :----------------- | :--------------------- |
| 新建笔记           | `Cmd/Ctrl+N`           |
| 保存当前笔记       | `Cmd/Ctrl+S`           |
| 切换实时预览与阅读 | `Cmd/Ctrl+3`           |
| 打开命令面板       | `Cmd/Ctrl+Shift+P`     |
| 新建窗口           | `Cmd/Ctrl+Shift+Alt+N` |
| 打开设置           | `Cmd/Ctrl+0`           |
