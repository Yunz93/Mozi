# 快速上手

欢迎使用 **墨知**（Mozi）。它把本地文件夹当作知识库，笔记就是普通的 `.md` 文件，不绑定云端账号，也不改成专有格式。

![墨知正式版|300](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787670846943.png)

## 30 秒走一遍主路径

1. **写作**：左侧文件树浏览知识库；用 **新建笔记**（默认 `Cmd/Ctrl+N`）开一篇新稿。工具栏在 **Live** 和 **阅读** 之间切换（默认 `Cmd/Ctrl+3`）。内容会自动保存，也可以手动保存（默认 `Cmd/Ctrl+S`）。
2. **小知助手**：打开工具栏的 **小知助手**，问一句：`上次关于发布流程的结论是什么？` 点「生成回答」一次即可；点引用会跳回原文。需要先看来源时用「仅检索」。
3. **发出去**：打开 [[03-发布与问库]]，用工具栏导出 **长图 / PDF**，或一键发到 **微信公众号草稿 / Simple Blog**。

粘贴图片会落到知识库里的附件目录，预览里直接可见。

## 新功能介绍

### Live 模式

正式版只保留 Live 和阅读。纯编辑、分屏已经去掉。Live 边写边渲染，所见即所得；点图片或公式可以回到源码再改。阅读用来专注看稿。

![Live 模式|200](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787670952816.png)

### 一键发布

工具栏提供两种发布方式：

- **微信公众号草稿**：配好 AppID / AppSecret 后，按预渲染样式发到公众号草稿。用公众号助手查看草稿再发布即可。
- **Simple Blog**：配套博客网页，部署到 Vercel 后，从墨知把文章推到仓库即可上线。设置方法见 [[03-发布与问库]]。

![一键发布|400](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787151343910.png)

### 图片分享

一键把当前文章生成分享长图，适合发朋友圈或小红书。

![图片分享|400](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787581997392.png)

### 小知助手

内置本地语义检索。可以全库搜索，也可以配置在线模型做智能问答，回答会带来源，点引用跳回原文。

![小知助手|400](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787669944524.png)

### Excalidraw 画板

侧边栏新建画板即可用。也兼容 Obsidian 的 `.excalidraw.md`。笔记里写 `![[drawing.excalidraw]]` 会嵌静态预览，点进去编辑。

![Excalidraw 画板|600](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787152633377.png)

### Markdown 便捷编辑

空行输入 `/` 可插入表格、提示文本、代码块、Mermaid 图表、待办事项、公式、Wiki 嵌入和脚注。`/3x4` 直接插入指定行列的表格。也可用 **命令面板**（默认 `Cmd/Ctrl+Shift+P`）搜索「插入表格」。对 Markdown 还不熟的话，从斜杠菜单开始就行。

![斜杠菜单|300](https://raw.githubusercontent.com/Yunz93/PicRepo/main/images/墨知正式版-1787669306323.png)

语法对照见 [[01-Markdown-语法示例]]、[[02-Obsidian-内联语法示例]]。

## 小提示

- 用 **命令面板** 搜索「发布」「小知助手」。
- 侧边栏搜索、当前文件查找、目录大纲等，可在 **设置 → 快捷键** 里查看或改绑。
- 示例笔记可以随便改；你改过的文件不会被后续同步覆盖。不需要的话，整份「示例笔记」文件夹删掉也行。
