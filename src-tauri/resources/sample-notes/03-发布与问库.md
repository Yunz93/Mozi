# 从本地知识库写到发出去

这篇是给新用户走一遍「写完就能发」的样例。可以改标题和正文，然后用工具栏导出长图，或发布到博客 / 微信公众号草稿。

## 上次关于发布流程的结论

上次发布流程的结论是：先在墨知里写完整篇 Markdown，再用工具栏发到微信公众号草稿或博客；封面图在发布时选择，正文里的本地图片会自动上传。不要先复制到网页编辑器里排版。

导出长图适合发到朋友圈或小红书；PDF 适合存档。发布失败时，先看是 AppID / AppSecret、IP 白名单，还是封面图没选。

## 怎么问库

打开 **问库**，问「上次关于发布流程的结论是什么」，点「生成回答」一次即可；点来源或引用可跳回本段。需要先看来源时用「仅检索」。

## 发布检查清单

1. **设置 → 发布**：填好公众号 AppID / AppSecret，或博客仓库与 Token。
2. 工具栏选择发布渠道。公众号发布前会显示接近手机宽度的图文预览。
3. 选封面图后提交。再次发布同一篇会更新原草稿，而不是新建一篇。
