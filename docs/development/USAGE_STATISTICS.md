# 匿名使用统计

墨知通过 Aptabase 的官方事件接收协议记录每日活跃趋势和网络出口 IP 的国家分布。
不自建接收后台，业务事件仅 `daily_active`。配置有效 App Key 的构建默认开启，用户可在设置 → 关于中关闭；已明确关闭的偏好会保留。

## 配置

1. 在 https://aptabase.com 注册托管账户，创建墨知项目，在 Instructions 中复制 App Key。
2. GitHub 仓库 Settings → Environments → TAURI → Environment secrets 中配置
   `MOZI_APTABASE_APP_KEY`。macOS、Windows、Linux 的发布构建任务均绑定 TAURI 环境，
   在原生编译步骤读取该 Secret；兼容同名仓库 Variable，Secret 优先。
   当前接入仅接受 `A-EU-数字` 或 `A-US-数字`，按 Key 路由至对应官方区域。
   App Key 是应用接收标识，不是账户密码；后台管理凭据不得嵌入应用。
3. 下一次构建会将配置编入应用；已有安装包不会因修改变量而自动获得此配置。
   本地可通过同名环境变量运行 `npm run tauri:dev`，调试事件与正式事件通过 `isDebug` 区分。
4. 配置有效 Key 后，新安装默认开启统计，无需在欢迎页勾选；欢迎页不显示统计选项。
   设置 → 关于中提供一段说明和开关。用户关闭后重启、升级不自动重新开启。
   未配置、用户已关闭、浏览器预览和 `desktop-e2e` 构建不向 Aptabase 发送请求。
   没有 Key 时界面说明当前版本暂不可用。

本地开发示例（将占位值替换为项目 App Key）：

```sh
MOZI_APTABASE_APP_KEY='A-EU-你的项目数字ID' npm run tauri:dev
```

App Key 通过构建时环境变量编入原生程序，不在软件设置中填写，也不应把真实值提交进仓库。
GitHub Actions 中在 TAURI 环境设置同名 Secret 即可，发布工作流的原生构建步骤已读取该值。

发布流程在绑定的 TAURI 环境中读取 Secret，不需要新服务器或额外 npm/Rust 依赖。
Key 仅注入需要编译应用的步骤，不写入日志；构建脚本跟踪变量变化。

## 数据与口径

- 业务事件：`daily_active`；无业务自定义属性。
- 系统字段：事件 UTC 时间、短期随机 sessionId、软件版本、系统类型、界面语言、
  渲染引擎类型、调试标记、发送实现版本。未知的系统/引擎版本留空。
- 不生成永久用户/设备 ID，不读取硬件标识；不发送笔记正文、文件名、文件路径、
  知识库名称、搜索词、账号、密钥、设备名称或异常日志。
- 由接收服务根据请求 IP 估算国家/地区。应用不查询第三方 IP 服务，不保存原始 IP，
  不经开发者服务器转发；VPN、代理和共享网络会影响国家归属和访客去重。
- 前台可见且聚焦、在线时检查当日活动；前台每分钟复查，跨 UTC 日期后可以发送新一天事件。
  原生层统一检查焦点、统计开关和每日标记，不统计单独的托盘窗口。
- 主进程互斥加本地日期标记保证同一安装的多窗口、重启或反复开关当天最多尝试一次。
  日期标记在请求前落盘；网络/服务失败会丢弃该次事件，当天不重试、不积压或补发历史。
  因此只能作为统计开启且成功联网的新版本用户的估计样本，不能当作准确全量用户数。
- Aptabase 的匿名去重标识按日变化。看每日活跃估计、每日趋势和国家覆盖，
  不将每日人数相加称为累计用户数，不声称可据此统计去重月活。

偏好和最后尝试日期位于应用本地数据目录 `usage-statistics.json`，不写入知识库或 Markdown。
多窗口共用原生偏好，变更通过事件同步界面；关闭后取消尚未完成的请求，
不再发起后续请求。已经抵达服务端的事件无法通过本地开关撤回。

## 实现选择

复用现有 `reqwest`、`chrono`、`rand`，只实现一个固定事件的原生发送。
官方插件的公开 API 没有运行时清空队列或取消发送能力；其轮询/退出刷新与本功能的
立即停止、无历史补发要求不同，因此采用同一官方 HTTP 协议，不引入插件的后台队列。
URL 仅由受校验的构建 Key 选择 EU/US 官方 HTTPS 地址，拒绝重定向；
前端命令不接收 endpoint、事件名或任意事件属性；请求超时 5 秒。

## 验收

- 无 Key、用户已关闭、纯浏览器、E2E 构建：无外发请求。
- 有效 Key 且无已存偏好：默认开启；首个前台活动落盘并接收一条协议匹配的事件。
- 已存 `enabled: false`：即使升级为默认开启版本仍保持关闭，不发请求。
- 损坏或不可读的偏好文件：不回退为开启发送，保留原有错误处理。
- 并发活动、多窗口和同日重启：当天不重复尝试。
- 跨 UTC 日期且继续前台使用：可产生下一天事件；仅后台挂起不触发新活动。
- 关闭开关：所有窗口状态同步，待发请求取消，无后续请求；重启保留关闭状态。
- 接收端错误、断网、超时：不阻塞编辑，不显示底层地址或密钥，不补发过期活动。
- 在真实 Aptabase 项目中核对 Debug/Release、事件名、国家分布和版本信息；
  缺少项目 App Key 时不能将本地模拟验证表述为真实看板联通成功。
