# 把笔记连起来

从 Obsidian 知识库迁过来时，可以继续使用常见的 Wiki 双链、图片嵌入、高亮与注释。这篇把每种写法和可点击的结果放在一起。

## Wiki 链接

**链接到一篇笔记：**

```markdown
[[01-Markdown-语法示例]]
```

试着打开：[[01-Markdown-语法示例]]。

**用显示别名让句子更自然：**

```markdown
先看 [[01-Markdown-语法示例|Markdown 排版练习]]。
```

先看 [[01-Markdown-语法示例|Markdown 排版练习]]。

**跳到目标笔记的指定标题：**

```markdown
[[01-Markdown-语法示例#标题与强调]]
```

直接打开 [[01-Markdown-语法示例#标题与强调|标题与强调]]，或 [[03-功能导览#选择分享渠道|分享渠道对照表]]。

**跳到当前笔记的标题：**

```markdown
[[#附件嵌入]]
```

试着跳到 [[#附件嵌入]]。

> [!tip] 把链接写进上下文
> 与其只放一个笔记名，不如补一句为什么要看它。例如：「整理成稿时，参考 [[03-功能导览|功能导览]] 中的检查清单。」

## 附件嵌入

### 嵌入图片

下面是新建演示知识库的实际截图，图片随示例笔记保存在 `resources` 目录中。

![墨知演示知识库的实时预览|720](resources/01-live-writing.png)

标准 Markdown 写法：

```markdown
![图片说明](resources/01-live-writing.png)
![图片说明|720](resources/01-live-writing.png)
```

Wiki 图片嵌入也可以指定宽度：

```markdown
![[resources/01-live-writing.png|720]]
```

这份示例还保留了本地图片 `resources/lbxx.jpeg`，可以对照下面的嵌入效果：

![[resources/lbxx.jpeg|240]]

### 嵌入笔记片段

不用复制整段内容，也能引用另一篇笔记的某一节：

```markdown
![[01-Markdown-语法示例#标题与强调]]
```

下面是实际嵌入的内容：

![[01-Markdown-语法示例#标题与强调]]

源笔记中的内容更新后，再查看嵌入位置，就能读到对应片段。

### 附件放在哪里

本组示例的截图与演示图片统一放在「示例笔记/resources」中，正文使用相对路径引用。

粘贴或插入本地图片后，检查正文中的相对路径。整个知识库迁移或备份时，笔记和附件目录需要一起保留。

图片不显示时，先检查文件是否存在、文件名大小写和路径是否一致。带目录的路径可以减少同名附件造成的混淆。

## 高亮与注释

==高亮适合标出一句需要回看的结论==。

```markdown
==需要回看的内容==
```

注释可留给以后编辑时看，在阅读模式中隐藏：

```markdown
%%这里记录编辑说明，不显示在阅读正文里。%%
```

这句话后面有一条演示注释。%%演示注释：下次修改时，再检查链接是否都能打开。%%

## 查看结构与链接

点击右下角 **大纲 / 链接**，可以查看当前笔记的标题结构和相关链接。写到一半需要回顾时，从大纲跳到对应小节，比反复滚动更方便。
